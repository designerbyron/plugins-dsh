## 2. Prueba de integración HTTP real (no unitaria)

`evidence/api-smoke.mjs` levanta el handler en `http.createServer` sobre `127.0.0.1:<efímero>`, con un
registro del Host simulado (uno `ok`, uno `missing-dir`, uno que **nunca** responde) y un perfil
temporal. Salida cruda: `evidence/api-smoke.json`.

**Medido: 17/17 casos en PASS** (`resumen: {casos:17, ok:17, fallos:[]}`).

> declarados se rechacen. Eso se comprueba en `tests/pa-workspaces.test.mjs` (forma exacta de la
> respuesta) y en esta prueba HTTP (status + cabeceras + cuerpo reales).

## 5. Lo que esta verificación **no** cubre

- El **Host real** de DeepSeek Harness no se ha ejecutado: el contrato del registro se leyó del
  paquete instalado (`dsh-workspace/src/entity.ts`, `dsh-session/src/index.ts`, copias en
  `evidence/`), pero la prueba contra el Host vivo exigiría instalar el plugin, y el mandato lo
  prohíbe (§8). El adaptador se ejercita con un doble que respeta ese contrato medido.
- No se ha publicado ni instalado nada: `npm pack --dry-run` sólo audita el contenido.
