# Política de reembolsos — Servicio de atención

Documento de prueba real, creado para la aceptación de LifeCode RAG. No contiene datos personales.

## Plazo

El reembolso se solicita dentro de los **treinta días naturales** siguientes a la compra. Pasado ese plazo,
la solicitud se escala al responsable de operaciones.

## Código de referencia

Las solicitudes de esta campaña llevan el código **ZX-4471**. Sin ese código, la solicitud se rechaza en
ventanilla y se devuelve al cliente con la plantilla de correo 12.

## Excepciones

- Compras con factura emitida a nombre de una empresa: revisión manual.
- Servicios ya consumidos: no procede reembolso salvo error de facturación.
