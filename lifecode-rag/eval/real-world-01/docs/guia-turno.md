# Guía operativa — Turno de tarde

Documento de prueba real, creado para la aceptación de LifeCode RAG. No contiene datos personales.

## Apertura

1. Comprobar el estado de la caja con el código **CAJA-2200**.
2. Registrar incidencias en el libro de turno antes de las 15:30.
3. Confirmar que el responsable de operaciones ha firmado el parte anterior.

## Cierre

El cierre se realiza a las 21:00. Si falta el parte firmado, se avisa al responsable de operaciones y se
anota la incidencia en el libro de turno.
